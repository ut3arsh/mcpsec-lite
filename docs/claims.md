Every architectural, behavioral, and quantitative claim in [`README.md`](file:///c:/Users/BIT%20PATNA/ai-agent-firewall/README.md) is mapped below to its backing specification/code/test evidence file and assigned an explicit epistemic status:

- **`measured on dev set`**: Quantified via scripted development benchmark runs ([`benchmark/results/dev_analysis_20261127_c7.md`](file:///c:/Users/BIT%20PATNA/ai-agent-firewall/benchmark/results/dev_analysis_20261127_c7.md) for `C7` and [`benchmark/results/dev_analysis_20261110_c6.md`](file:///c:/Users/BIT%20PATNA/ai-agent-firewall/benchmark/results/dev_analysis_20261110_c6.md) for `C0`–`C6`) using local fake upstreams (**not** held-out or multi-LLM benchmark evaluation).
- **`by design`**: Architectural invariant specified in contract docs and enforced by unit/property/integration tests.
